Traditional RAG pipeline:
RAG is a technique that allows you to query your own private data with an LLM in an end-to-end manner. 


- document structure -> pdf, html, excel, db
- data ingestion pipeline -> extract, split, embed, store
- retrieval pipeline -> query, embed, search, rerank, generate
